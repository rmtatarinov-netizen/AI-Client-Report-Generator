# Excel-отчёт АО «Святогор»

Инструмент собирает отчёт на основе `Отчёт.xlsx` и нового реестра предписаний.
По умолчанию создаются два файла: Excel-отчёт и PDF того же отчёта.
Оригинальные Excel-файлы не изменяются.

## Файлы

- `build_template.py` — собирает `Отчёт_шаблон.xlsx` из `..\..\Отчёт.xlsx`.
- `generate_report.py` — формирует отчёт за указанный период.
- `common.py` — общие функции: замена ссылок, нормализация формул, копирование данных, пересчёт Excel и PDF-экспорт.
- `Отчёт_шаблон.xlsx` — готовый шаблон с локальными листами `АО Святогор` и `АО УММ2`.

## Требования

- Python 3.10+.
- `openpyxl`.
- Microsoft Excel для автоматического пересчёта формул и экспорта PDF.
- `pywin32` для управления Excel через COM.

Установка зависимостей:

```powershell
pip install -r requirements.txt
```

## Куда класть реестры

Реестры хранятся в папке `registries` в корне проекта:

```text
registries\
  Реестр предписаний АО Святогор_04.11.2026.xlsx
  archive\
    Реестр предписаний АО Святогор_27.10.2026.xlsx
```

- Текущий реестр кладётся в `registries\`.
- Старые реестры переносятся в `registries\archive\`.
- Генератор ищет файлы только в `registries\`, архив не использует.
- Поддерживаются `.xlsx` и `.xlsm`.
- Если файлов несколько, берётся самый свежий по дате изменения.
- Имя файла: `Реестр предписаний АО Святогор_ДД.ММ.ГГГГ.xlsx`, где дата — дата актуальности реестра, а не период отчёта.
- Папка `registries\` исключена из git, так как содержит рабочие данные.

Для файла в другом месте используйте `--registry` (пример ниже).

## Формирование отчёта

Период задаётся вручную при запуске:

```powershell
python excel_report\generate_report.py --start 11.09.2026 --end 08.10.2026
```

По умолчанию берётся самый свежий файл `Реестр предписаний*.xlsx` или `*.xlsm` из папки `registries`.
Результаты сохраняются в:

```text
reports\svyatogor_report_ГГГГ-ММ-ДД_ГГГГ-ММ-ДД.xlsx
reports\svyatogor_report_ГГГГ-ММ-ДД_ГГГГ-ММ-ДД.pdf
```

PDF содержит только лист `Отчёт`. Служебные листы `АО Святогор` и `АО УММ2` в PDF не попадают.
В PDF печатается только область `A1:F<последняя строка>`: столбцы `G:Y` скрыты, сетка Excel при печати отключена.
Строки, содержащие `Предписаний больше нет`, автоматически скрываются в Excel и PDF.
В каждом разделе `Замечания АО` при отсутствии реальных замечаний остаётся одна строка `Предписаний нет`, остальные такие строки скрываются. Если в разделе есть реальные замечания, все строки `Предписаний нет` скрываются.
PDF экспортируется через установленный Microsoft Excel после полного пересчёта формул. При сбое пересчёта или экспорта причина записывается в `reports\generate_report_error.log`.

Явно указать реестр и файл результата:

```powershell
python excel_report\generate_report.py `
  --registry "registries\Реестр предписаний АО Святогор_04.11.2026.xlsx" `
  --start 11.09.2026 `
  --end 08.10.2026 `
  --output "reports\Святогор_сентябрь.xlsx"
```

В этом случае PDF будет сохранён как `reports\Святогор_сентябрь.pdf`.

## Параметры

- `--start` — начало периода, `ДД.ММ.ГГГГ`.
- `--end` — конец периода, `ДД.ММ.ГГГГ`.
- `--registry` — путь к реестру; по умолчанию ищется в `registries`.
- `--template` — путь к шаблону, по умолчанию `excel_report\Отчёт_шаблон.xlsx`.
- `--output` — путь к Excel-результату; PDF создаётся рядом с тем же именем и расширением `.pdf`.
- `--umm2` — отдельный файл с листом `АО УММ2`, если данные УММ2 нужно обновить.
- `--no-pdf` — создать только Excel, без PDF.
- `--no-recalc` — не запускать Excel; PDF при этом не создаётся, отчёт нужно открыть и пересчитать вручную.

## Что делает генератор

- Копирует данные реестра в лист `АО Святогор`.
- Пересчитывает служебные колонки `U` и `V`.
- Записывает даты периода в `G9` и `H9`.
- Оставляет данные `АО УММ2` из шаблона.
- Заменяет внешние ссылки `[1]` на локальные листы.
- Приводит диапазоны формул к единому лимиту строк.
- Пересчитывает книгу через Excel и сохраняет результат.
- Экспортирует лист `Отчёт` в PDF через Excel.

## Исправления в `АО УММ2`

В шаблоне исправлены проблемные даты:

- `J466`, `J467`: `15.07.0204` → `15.07.2024`.
- `J1435`, `J1436`: `30.092026` → `30.09.2026`.
- `J1205`: недопустимая дата → `08.04.2026`.
- `K248`: текст → `07.02.2024`.
- `R1435`: восстановлена формула расчёта просрочки.

После исправлений показатель «Истек срок устранения» в УММ2 увеличился на 3.

В `АО Святогор!F802` остаётся исходное значение `#ERROR!`. Это текстовое поле без надёжного способа автозамены; генератор выводит его в проверке как предупреждение.

## Пересборка шаблона

Если изменился исходный `Отчёт.xlsx`:

```powershell
python excel_report\build_template.py
```

Скрипт:

- загружает исходную книгу с сохранением внешних связей;
- применяет исправления;
- заменяет внешние ссылки и нормализует формулы;
- сохраняет промежуточную книгу;
- повторно сохраняет результат без внешних связей.

## Проверка результата

Генератор выводит:

- количество внешних формул `[1]`;
- количество частей `externalLink`;
- список ячеек с ошибками.

Для корректного отчёта внешних ссылок и частей `externalLink` должно быть `0`.
Допустимое предупреждение — `АО Святогор!F802=#ERROR!`.

После успешного запуска в консоли выводятся пути к Excel-файлу и PDF.
Если PDF не создался, команда завершается с ненулевым кодом, а Excel-файл остаётся сохранённым.
